# Distill.codes Feedback

Public bug reports, feature requests, and product feedback for
[Distill.codes](https://distill.codes).

Distill is a drop-in proxy for Claude Code and Codex that helps AI coding
agents produce smaller, cleaner, lower-cost code changes.

## Report a Bug

Use the bug report form:

https://github.com/MyDream-Labs/distill.codes/issues/new?template=bug_report.yml

Include:

- what happened
- what you expected
- where it happened: landing, dashboard, billing, proxy, Codex, or Claude
- steps to reproduce
- browser, OS, CLI, or agent version when relevant

## Request a Feature

Use the feature request form:

https://github.com/MyDream-Labs/distill.codes/issues/new?template=feature_request.yml

Tell us what problem you are trying to solve and how the feature would help.

## General Feedback

Use the feedback form:

https://github.com/MyDream-Labs/distill.codes/issues/new?template=feedback.yml

## Please Do Not Post Publicly

Do not include secrets or private data in public issues:

- API keys
- proxy URLs or Distill keys
- billing details
- private source code
- private prompts, logs, or customer data

For private support, billing, or security-sensitive reports, email:

support@distill.codes
